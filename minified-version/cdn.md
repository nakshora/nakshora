# CDN files

| URL                                                                                  | What it is                                                                                     |
| ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| `https://cdn.jsdelivr.net/gh/nakshora/nakshora@main/dist/css/nakshora.min.css`       | Current full build (minified). Generated by `scripts/generate-css.mjs`.                        |
| `https://cdn.jsdelivr.net/gh/nakshora/nakshora@main/dist/css/nakshora.css`           | Current full build (readable).                                                                 |
| `https://cdn.jsdelivr.net/gh/nakshora/nakshora@main/min.main.css`                    | Historical entry point. **Byte-identical to `dist/css/nakshora.min.css`** (drift-tested).      |
| `…@main/dist/css/nakshora.min.css.br` / `.gz`                                         | Precompressed sidecars (132,967 B / 575,520 B) for self-hosting; see `docs/INSTALLATION.md`.   |
| `https://cdn.jsdelivr.net/gh/nakshora/nakshora@main/minified-version/v1.0.0.css`     | Frozen v1.0.0 stylesheet (2024 design system, 1,015 classes). Never regenerated.               |

## Why `min.main.css` still exists

Sites built against v1 linked `…@main/min.main.css`. That URL keeps working, but since 3.0 it serves the
current engine's full build, not the v1 design system. The v1 classes that the engine does not know
(`btn-neon`, `card-glass`, `w-1-2`, `xxl:`/`uhd:`/`k8:` screens, …) are listed in `docs/MIGRATION.md`
and are re-created as a real Nakshora config in `site/nakshora.config.mjs`.

Need the exact v1 look with zero changes? Pin the frozen file:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/nakshora/nakshora@main/minified-version/v1.0.0.css" />
```

## Generating

```bash
pnpm build:core
node scripts/generate-css.mjs   # dist/css/nakshora{,.min}.css + .br/.gz sidecars + min.main.css
node scripts/build-site.mjs     # site/index.min.css (the landing page's own JIT build)
```

The tests in `packages/@nakshora/core/test/site.test.ts` fail when any of these files drift from a
fresh build.
