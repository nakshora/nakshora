## [2.0.0] - 2026-09-12

### 🎉 Major Release: Nakshora 2.0

Complete rewrite with modern architecture and TypeScript support!

### ✨ Added

- **TypeScript Support**: Full type-safe configuration system
- **CSS Generator**: Advanced utility-first CSS generation from configuration
- **5 Built-in Themes**: 
  - Neon Cyber (vibrant, high-contrast)
  - Pastel Dream (soft, calming)
  - Brutalist (minimalist, stark)
  - Minimalist (clean, professional)
  - Nature (organic, earthy)
- **Complete Utility System**:
  - Display & Layout utilities
  - Spacing (margin, padding, gap)
  - Typography (size, weight, alignment)
  - Colors (50 colors × 10 shades each)
  - Flexbox & Grid
  - Borders & Shadows
  - Effects (opacity, blur)
  - Transforms & Transitions
  - 6 Responsive breakpoints
- **Comprehensive Documentation**:
  - Installation guide
  - Getting started tutorial
  - Complete utilities reference
  - Configuration API documentation
  - Code examples & patterns
  - Theme guide
- **Modern Build System**:
  - Webpack configuration
  - TypeScript compilation
  - CSS generation and minification
  - Source maps support
  - ESM bundle output
- **NPM Publishing Ready**:
  - .npmignore configuration
  - Publishing guide
  - CI/CD ready
  - Full package.json setup
- **Development Tools**:
  - Development server with hot reload
  - Test suite setup
  - Linting & formatting
  - Build scripts

### 🔧 Changed

- Complete architecture redesign
- Moved from static CSS to programmatic generation
- Enhanced color system with 50+ colors
- Improved breakpoint system
- Better spacing scale

### 🐛 Fixed

- N/A (First release of v2)

### 🔒 Security

- Dependencies are secure and up-to-date
- No known vulnerabilities

### 📚 Documentation

- Complete rewrite of all documentation
- Added interactive code examples
- Created comprehensive guides
- Added theme comparison charts
- Published installation instructions for all frameworks
